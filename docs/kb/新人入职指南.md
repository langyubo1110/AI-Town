# 新人入职指南

## 第一天做什么

上午到 3 楼 IT 工位领电脑和门禁卡，出示身份证即可。设备默认是 MacBook Pro 14 寸，
需要 Windows 要提前跟 IT 说。

下午做三件事：加入团队飞书群、找导师要一份「本周任务清单」、通读《研发规范》。

## 账号申请

邮箱、代码仓库、数据库、内网 VPN 四类账号走 IT 门户统一申请，1 个工作日内开通。
数据库账号要额外找 DBA 审批，需要说明要访问哪个库、做什么。

## 导师制度

每位新人配一位导师，负责前三个月的技术答疑和成长反馈。
导师不是直属领导，可以放心问「这个我是不是问了个傻问题」。

## 试用期

试用期 3 个月，第 1 个月末和第 3 个月末各有一次反馈会。
反馈会不是考试，主要聊「哪里卡住了、需要什么支持」。

转正需要完成一个独立的小需求，从评审到上线走完整流程。

## 常用信息

- 技术分享：每周五下午 16:00，会议室 A
- 报销：每月 25 日前提交上月单据
- 加班调休：加班满 4 小时可申请半天调休，当月有效
